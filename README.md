# Cirkle 🟢

Бот для подсчёта телеграм-кружков. Ты пересылаешь боту видео-кружок —
он считает, сколько их должно было прийти к этому моменту (по интервалу
30 минут) и сколько реально пришло.

## Как работает

- Пересылаешь боту `video_note` (кружок) → засчитывается.
- `/go` — зафиксировать точку отсчёта (с этого момента «капают» ожидаемые кружки).
- `/stats` — должна / прислала / долг.
- `/reset` — обнулить.
- Режим 24/7, интервал настраивается в `.env`.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Скопируй `.env.example` → `.env` и вставь `BOT_TOKEN`.
3. Установи зависимости и запусти:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bot.py
```

4. Напиши боту `/start`, потом `/go` — и пересылай кружки.
